## Ringkasan Modul

### 1. [Modul 09: Redundansi Data dan Denormalisasi](./modul_09/)
Membahas teknik evaluasi redundansi terencana untuk meningkatkan efisiensi pembacaan data agregasi biaya pemeliharaan aset tanpa mengorbankan integritas data.

### 2. [Modul 10: DBMS dan Aplikasi Basis Data](./modul_10/)
Membahas perancangan skema relasional, penegakan kunci asing (*Foreign Key Constraints*), serta pengujian transaksi operasional pada sistem aplikasi basis data.

### 3. [Modul 11: Perkembangan DBMS dan Lingkup Penerapan](./modul_11/)
Membahas studi komparatif DBMS (MySQL 8.4, PostgreSQL, MongoDB), analisis basis data berorientasi objek (OODBMS), implementasi tipe data semi-terstruktur native JSON, dan integrasi lingkup penerapan sistem SIMPAK.
